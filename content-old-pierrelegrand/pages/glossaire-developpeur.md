# Glossaire du Dev - Vocabulaire des Développeurs Web

## Flutter SDK

**Kit de développement open source Google**

Flutter est un kit de développement logiciel d'interface utilisateur open-source créé par Google. Il permet de développer des applications pour Android, iOS, Linux, Mac, Windows, Google Fuchsia et le web depuis une seule base de code.

L'avantage principal réside dans l'unification du code source. Cette plateforme gère automatiquement les différences entre supports (mobile, desktop, etc.), permettant aux développeurs de se concentrer sur la logique plutôt que sur les spécificités techniques de chaque plateforme.

## Node.js

**Plateforme open source en JavaScript**

Node.js est une plateforme open source écrite en JavaScript orientée vers les applications réseau hautement scalables. Elle utilise la machine virtuelle V8, la librairie **libuv** pour sa boucle d'événements, et implémente les spécifications CommonJS sous licence MIT.

Un avantage significatif : Node.js implémente le protocole HTTP natif, éliminant la dépendance envers des serveurs web externes comme Nginx ou Apache.

## npm

**Gestionnaire de paquets pour JavaScript**

npm est LE gestionnaire de paquets incontournable dans l'écosystème Node.js. Il se compose d'un client en ligne de commande (commande `npm`) et d'un registre en ligne contenant des paquets publics et privés payants.
