## Introduction

Ce tutoriel enseigne comment créer une application de création, de récupération, de mise à jour et de suppression (CRUD) à l'aide de Flutter et Strapi. Les développeurs apprendront à utiliser le package HTTP pour appeler les points d'accès Strapi et construire des écrans permettant d'ajouter, récupérer, mettre à jour et supprimer les données utilisateur.

## Prérequis

- NPM
- Node.js
- Flutter SDK

## Concepts clés

### Qu'est-ce qu'un CMS sans tête ?

Un CMS headless fonctionne comme "le seul référentiel de contenu qui sert de back-end pour vos applications front-end." Il délivre le contenu via API REST ou GraphQL plutôt que par une interface web traditionnelle. Cette approche sépare le stockage du contenu de sa présentation.

### Pourquoi Strapi

Strapi est "un framework JavaScript qui simplifie la création d'API REST." Il permet aux développeurs de:
- Définir des types de contenu
- Gérer les relations entre données
- Héberger des ressources multimédias

Tout cela sans expertise backend requise.

## Aperçu du projet

La construction d'applications complètes nécessite des composants front-end et back-end interdépendants. Strapi, reposant sur Node.js, offre une alternative moderne aux CMS traditionnels en permettant la gestion autonome des API.
